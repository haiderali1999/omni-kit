                      Always-on features
                      
    
                      These run on every page you visit. Switch off any you don't use —
      takes effect on tabs opened or refreshed after you toggle it.
                      
    
                      
      
    
                      
    
                      
      
    
                      
    
                      
      
    
                      
    
                      Off by default: it patches console.error site-wide to capture it for bug
      reports, and Chrome then attributes ANY site's console.error calls to OmniKit's own
      "Errors" entry on chrome://extensions — including errors that have nothing to do with
      OmniKit. Turn it on right before you need to file a bug report, not as a background habit.
                      

    
                      

    
                      Backup & restore
                      
    
                      Export everything OmniKit has stored (sessions, clips, watches, snippets,
      candidates, checklists, alerts, settings) as one JSON file, then import it in OmniKit
      on another browser/machine to carry your data over.
                      
    
                      
      
      
      
    
                      
    
                      Importing replaces all current OmniKit data on this device with the
      file's contents. This can't be undone.
